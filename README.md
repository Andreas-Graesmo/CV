# Andreas Græsmo – CV-nettside

Statisk CV-nettside klar for GitHub Pages.

## GitHub Pages

1. Last opp innholdet i denne mappen til roten av et GitHub-repository.
2. Gå til **Settings → Pages** i repositoryet.
3. Velg publisering fra en branch og bruk repositoryets hovedbranch/root som kilde.

Nettsiden har ingen CDN-avhengigheter og består av vanlig HTML og CSS.
